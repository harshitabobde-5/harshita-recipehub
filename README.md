# 🍲 Harshita RecipeHub

A modern and responsive Recipe Application built with React.js that helps users discover delicious recipes with a clean and interactive user experience.

## ✨ Features

- 🔍 Search recipes instantly
- 🍽️ Explore meal details
- 📱 Fully responsive design
- ⚡ Fast performance with React + Vite
- 🎨 Modern and clean UI
- 🌐 API-based dynamic recipe data

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/harshitabobde-5/harshita-recipehub.git
```

Navigate to the project folder:

```bash
cd Recipe App
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
